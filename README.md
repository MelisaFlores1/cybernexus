
# CYBERNEXUS

Página web educativa sobre ciberseguridad, desarrollada con HTML, CSS y JavaScript.

## Funciones

- Diseño adaptable a computadoras y celulares.
- Verificador educativo de contraseñas.
- Generador de contraseñas aleatorias.
- Reto interactivo para identificar correos sospechosos.
- Información sobre privacidad y protección digital.

## Archivos

- `index.html`: contenido de la página.
- `style.css`: diseño y estilos.
- `main.js`: funciones interactivas.

## Publicación

El proyecto puede publicarse gratuitamente con GitHub Pages.

## Nota

Proyecto demostrativo y educativo. No es un sistema real de detección de amenazas. No se deben introducir contraseñas reales en herramientas de demostración.
